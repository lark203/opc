# 功能实现准则

## 1. 项目基础

- 在 `art-design-pro` 项目中实现功能
- 实现功能逻辑主要参考 `plus-ui` 项目中对应功能

## 2. 样式与组件

- 实现的页面功能样式需要和已有的 `art-design-pro` 项目中保持一致
- 尽量使用 `art` 中封装的组件或者 hooks 进行实现

## 3. 数据处理

- 实现功能的时候，能使用字典值的情况优先使用字典值，不要硬编码
- 展示 id 的地方，尽量替换为对应名称、昵称等，尽量直观

## 4. 响应式设计

- 界面中的组件宽高尽量使用百分比宽高
- 需要适配手机浏览器

## 5. 代码质量

- 类型确定的不要使用 `any` 进行替代
- 页面根节点不要添加注释
